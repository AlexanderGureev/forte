# Forte Piano Improvisation MVP

Client-side MVP на Vite, React и TypeScript: интерактивный визуальный справочник по тональностям, гаммам, диатоническим трезвучиям и базовым прогрессиям для начинающих пианистов.

Приложение является визуальным справочником. В MVP нет звука, MIDI-ввода, упражнений, проверки игры, аккаунтов, backend, routing и сохранения состояния между запусками. Состояние живет только в памяти текущей вкладки.

## Команды

```bash
npm install
npm run dev
npm run test
npm run build
```

- `npm install` устанавливает зависимости проекта.
- `npm run dev` запускает локальный Vite dev server.
- `npm run test` запускает Vitest-проверки.
- `npm run build` выполняет `tsc -b` и production-сборку Vite.

## Scope MVP

Стартовое состояние - `C Major`: видна 3D-студия с объемной клавиатурой, HUD, подсветка нот гаммы, тоники и активного аккорда. Основной сценарий - исследовать, как одна и та же теория пересчитывается при смене тоники, лада, прогрессии или выбранного аккорда.

Музыкальная теория рассчитывается в `src/music/**` и derived state/view models. 3D-сцена и UI только отображают готовые модели: они не являются источником музыкальной теории и не должны содержать собственные правила построения гамм, аккордов, прогрессий или key signature.

## Тональности и Minor

`Minor` в интерфейсе MVP всегда означает `Natural Minor`. Гармонический и мелодический минор не реализованы.

Поддержанные `Major` тоники:

`C`, `G`, `D`, `A`, `E`, `B`, `F#`, `C#`, `F`, `Bb`, `Eb`, `Ab`, `Db`, `Gb`, `Cb`.

Поддержанные `Natural Minor` тоники:

`A`, `E`, `B`, `F#`, `C#`, `G#`, `D#`, `A#`, `D`, `G`, `C`, `F`, `Bb`, `Eb`, `Ab`.

`recommended` - ручная метка для короткого списка стартовых тональностей: `C Major`, `G Major`, `D Major`, `F Major`, `A Minor`, `E Minor`, `D Minor`. `difficulty` считается отдельно по количеству знаков при ключе: `easy` для 0-1 знака, `medium` для 2-3, `advanced` для 4-7.

`diminished`-аккорды входят в диатонические трезвучия, отображаются с маркером `dim` и считаются напряженными/advanced, а не ошибкой пользователя.

## Основные сценарии проверки

1. Выбрать тонику: кликнуть белую клавишу на 3D-клавиатуре, выбрать enharmonic option после клика по черной клавише или выбрать тональность в панели `Тональность`.
2. Переключить `Major/Minor`: использовать segmented control в верхнем HUD; `Minor` переключает на `Natural Minor`.
3. Выбрать progression: нажать preset в блоке `Прогрессия` (`I-V-vi-IV`, `I-IV-V`, `ii-V-I` для Major; `i-VI-III-VII`, `i-iv-v`, `i-VII-VI-VII` для Natural Minor).
4. Выбрать chord card: нажать карточку в панели `7 аккордов лада`; если степень есть в текущей прогрессии, активный шаг синхронизируется, иначе выбирается ручной аккорд.
5. Переключить `Notes/Degrees`: открыть `Вид` и переключить подписи клавиш между `Ноты`, `Ступени` и `Скрыть`.
6. Открыть theory overlay: нажать `Теория` или кнопку `i` рядом с тональностью, гаммой, аккордами, прогрессией, активным аккордом или легендой цветов.
7. Включить focus mode: нажать `Фокус`; режим скрывает вторичные панели и оставляет основную сцену с ключевыми контролами.

Горячие клавиши UI: `ArrowLeft`/`ArrowRight` переключают шаг прогрессии, `M` переключает `Major/Minor`, `L` скрывает или показывает подписи, `D` переключает `Notes/Degrees`, `F` включает focus mode, `?` открывает theory overlay.
